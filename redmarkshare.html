For files over 10 GB, use a Chromium-based browser with file-saving support and sufficient free disk space. RedmarkShare streams the received file to disk where the File System Access API is available; it avoids building a single giant Blob in memory.
Important limits to understandBrowser peers use WebRTC and can connect to WebTorrent-compatible peers, not every conventional BitTorrent client. A public WebSocket tracker helps peers discover each other; it does not store the file. Both sides must stay online during the transfer. Network restrictions may prevent a connection. This first version does not promise resume after the page closes, and mobile browsers may impose storage or background-tab limits.
RedmarkShare is an experimental peer-to-peer transfer tool. Share only files you have permission to distribute.
