For files over 10 GB, use a Chromium-based browser with file-saving support and sufficient free disk space. RedmarkShare streams the received file to disk where the File System Access API is available; it avoids building a single giant Blob in memory.
⚙ Connection relay (TURN)Not set · direct connections only

If the receiver stays on "Finding peers…" or reports that the connection failed, the two devices cannot reach each other directly. This is common on mobile data, where carriers put phones behind shared NAT. A TURN relay forwards the encrypted WebRTC traffic between them. Providers such as Metered and Cloudflare offer free tiers. Add the relay on the sending device; adding it on the receiver as well gives the best chance. Details are saved only in this browser.

Same Wi-Fi on both devices usually works without a relay.
Important limits to understandBrowser peers use WebRTC and can connect to WebTorrent-compatible peers, not every conventional BitTorrent client. A public WebSocket tracker helps peers discover each other; it does not store the file. Both sides must stay online during the transfer. Network restrictions may prevent a direct connection, especially on mobile data; use the same Wi-Fi or a TURN relay. This first version does not promise resume after the page closes, and mobile browsers may impose storage or background-tab limits.
